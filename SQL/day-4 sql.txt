UPDATE
------------
update table-name set column-name=value where some condition;

DELETE
--------------
delete the records based on some conditions
Syntax:- delete from table-name where some condition;

TRUNCATE
-------------
remove all records present in a table
Syntax:- truncate table table-name;

differences b/w drop, delete, truncate
---------------------------------------------
1.drop:-
--------
removes the table or object
table structure + data
table structure removed
performance is slow(due to full removal)

2.delete
----------
1.removes specific rows from a table
specific rows(based on condition)
table structure intact
performance is slow(row-by-row)

3.truncate
---------
removes all rows, keep structure
all rows
table structure intact
performance is fast(bulk deletion)

Data control language
---------
DCL(Data control language) commands Manages permissions and accesses control on database objects.

they are two type of commands
1.grand
2.revoke

COMMON PRIVILAGES
-----------
select ---> read data
insert ---> insert data
update ---> modify data
delete ---> remove data
all privilage ---> full access

how to user creation
---------------
CREARE USER 'USERNAME' IDENTIFIED BY 'PASSWORD'


GRANT
------
  GRANT PRIVILAGE ON TABLE_NAME TO 'USERNAME'

REVOKE
------
  REVOKE PRIVILAGE ON TABLE_NAME FROM 'USERNAME'
